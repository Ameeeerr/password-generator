## Password Generator (Python)

A simple Python program that generates random passwords based on your needs.

## What it does

    Asks how long you want your password to be.

    Let's you choose to include numbers or symbols.

    Creates a random password based on your choices.

    Allows you to generate multiple passwords at once.

## Requirements

    Python 3.x

    No extra libraries needed (uses the built-in random module).

## How to use

    Download password_generator.py.

    Open your terminal or command prompt.

    Run the script
